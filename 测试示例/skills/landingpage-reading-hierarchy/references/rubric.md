# 阅读层级定分细则

来源：落地页排版评测标准 v0.1。本技能只执行角度 A。B、C、D、E 不适用，不参与降档，也不要在报告里给它们打分。

本分叫「阅读层级分」。它不是标准 3.4 的整页排版分。整页 5 分还要求间距档和栏宽；那些不在本次范围。

状态：候选。没有样本校准。字号数字不能单独决定档位。

## 判断目标

页面是否存在可重复的字号阶梯，扫描时能否先看到该节最重要的文字。依据是排版工艺，不是某份品牌规范。

不判断某一段正文好不好读，也不判断左右边缘是否对齐。短标签可作层级证据，不作正文证据。海报式大标题、正文很少，只要主信息和次信息分得开，A 可以成立。

## 取证步骤

1. 标出首屏的主标题、辅助说明、行动文字，以及其后每个主要节的节标题和节内正文。
2. 记录它们的字号、字重和相对位置。位置只用脚本量到的坐标，不凭感觉。
3. 检查是否至少形成可区分的角色。常见是三档：主标题、节标题、正文。两档也可以成立，但必须在整页稳定复用，并且主次不会看反。
4. 沿页面向下看，节标题是否用同一角色进入下一节。
5. 两段文字字号接近时，看字重、位置和周围间隔是否仍能分出先后。分得出，记为成立；分不出，按出现范围记入明显或严重。

纯图形区域里的文字如果没有可测量的计算字号，该区域注明「测不到计算字号」。不要用图片观感补一个字号。

导航短标签、按钮上的两三个字可以说明首屏里有行动文字，不能拿来充当节标题或正文档。

## 严重度

严重度服务定分，不单独打分。重叠、裁切、横向溢出不归阅读层级，即使脚本里能看到也不要据此降档。

- **阻断。** 整页无法区分标题和正文，也看不到分组。
- **严重。** 首屏层级分不开，或两个以上主要区块层级分不开。
- **明显。** 能指出某个次级标题偏弱，或某一节的层级失效。首屏主路径和多数区块仍然清楚。
- **轻微。** 一两处不影响阅读的边缘偏差。整页完成度还在。

同一事实只记一次。多条明显问题仍然是明显，不累加成严重。

手机视口把多栏重排后，标题顺序或字号角色消失：层级事实仍由阅读层级定性，按它落在首屏还是多节来定严重或明显。

## 定分

按这个顺序，命中一条就停止。

1. 页面打不开、字体未就绪、或主标题只存在于图片里因而没有计算字号：整份结果为**未判定**。未判定不是 0 分。部分区域测不到字号、其余 HTML 文字足以判断时，只把测不到的区域记未判定，其余照常定分。
2. 稳定态没有任何可观察的内容结构（空白页、加载失败后的空文档）：**0 分**。少一个模块、使用了大图首屏、没有某个按钮，都不能判 0 分。
3. 有阻断：**1 分**。
4. 没有阻断、有严重：**2 分**。其他节表现好，不升档。
5. 没有阻断和严重、有明显：**3 分**。
6. 只有轻微问题或没有问题，但指不出沿各节重复的字号角色，或节标题进入下一节的方式不稳定：**4 分**。
7. 没有明显、严重或阻断，并且能指出被实际使用的字号阶梯：角色沿各节重复，节标题以同一角色进入下一节：**5 分**。大标题少、留白多，只要这套阶梯指得出来，就可以是 5 分。

用户声明只评桌面时，手机记不适用，只按桌面定分。

## 改进时允许动的东西

只允许改字号、字重和位置。不改文案含义，不改颜色，不改图片，不评转化。

建议的目标字号必须来自这页已经成立的角色。某一节标题偏弱，就让它回到其他节标题那一档，不要另造一档。整页还没有阶梯时，只写角色关系：主标题大于节标题，节标题大于并重于正文，各节标题同一档。若必须写出像素，标明这是暂定实现值，不是标准里的及格线。
